        卡丁在舱门于他身后打开时没有转身。被封起的舱室之外，走廊沉滞静寂一如阿里曼当初派他守卫的时候…那是多久以前了？他听得一声咳嗽，还有一声迟缓的艰难呼吸，可他依然没有转身。

        自从他上一次听得什么杂声、抑或做出什么呼吸之外的动作，已经是多久过去？他不知道。那无关紧要。

        “帮帮我，卡丁。”阿里曼说。卡丁应声望去，看见了阿里曼，站在敞开的门里，全身的重量倚在金属的门框上。他的铠甲泛着层玻璃釉质的光泽，仿佛曾有火焰将它灼得油亮。有冰霜附在那身铠甲的凹陷里。透过开敞的门，卡丁看得焦黑的灼痕遍处蔓延在地板上、墙壁上。唯有那黑石的棺前有一小圈金属不曾被灼下痕迹。有水滴随着寒霜开始融化，自天花板上一滴滴落下。卡丁想，那灼痕看起来仿佛曾有浩然的炽热羽翼张展开来、一直触碰到墙壁上。

        阿里曼望着卡丁；他的双眼仿佛深深沉进了颅骨里，皮肤在那张英俊面庞的骨头上绷得那样紧。就在卡丁注视着的时候，一滴血珠凝在了他的唇角，滋长，顺着他的下颏流了下去。

        阿里曼缓缓吸了口气，而卡丁听得了那呼吸中簌簌的杂音、与潮湿的咯咯声。

        “卡丁。”阿里曼再一次开口，开始缓缓地倚着门框滑了下去。

        卡丁接住了他，以一只活塞驱动的手紧紧抓住了他一条胳膊。机械的肢体在触碰上那术士的地方一阵微微的刺痛；那感觉困惑着他，可他什么也没有说。缓缓地，他拉着阿里曼站了起来。

        我可以杀了他，他一边扶起那术士、稳起他的身躯，一边心里想着。现在，鲜血正在从阿里曼的唇间涓涓地滴落，他的眼也闭上了。现在，我可以杀了他，而他没法做任何事来阻止我。

        “又在想着杀了我么，卡丁 *1？”

        “你曾说过你会把我的念头留给我自己的。”

        “我确实这么做了。那只是个猜测。”阿里曼染血的唇微微抽动了一下，“此外，我需要力量去做的事情，可比读你念头来得重要得多。”他忽然痉挛起来，双眼睁开了，瞳孔在充满血丝的眼白中散得那样大。他静了下来，彻彻的滞。卡丁嗅到炽热金属的味道，低头看去。他握着阿里曼手臂的手指正灼热得发光。

        阿里曼很慢很慢地呼出一口气来，那呼吸在温暖的空气里凝着白霜。他的瞳仁凝缩回去，雾笼着他双眼的血丝一点点流尽了，露出那双眼眸平日里冰冷的蓝。他直起身，仿佛力量正在回归身上，尽管他的面容依然看上去那样憔悴而空洞。他抬起一只覆甲的手，擦去了下颏上的血迹。

        “谢谢你。”阿里曼说。卡丁放开了手。阿里曼迈了一步，一下踉跄，扶在了墙上。“该死的银片。”他说着，啐了一口。染血的唾沫在地面上嘶嘶地响。阿里曼又迈了一步，这一次看上去稳确了些，尽管卡丁看得出，那动作是纯然的强撑意志。阿里曼抬起头望向那漫长的走廊，又望回身后那敞开大门之后、灼得焦黑的房间。“封上它吧。”他说。

        卡丁点了点头。可阿里曼已经在转身离开了。卡丁忽然感到有什么他无法确切安放的情感涌了上来。他已经麻木了那样久，以至于这感情令他措手不及得惊异。不知为何地，他期待着阿里曼说些别的什么，期待着阿里曼会有所不同；而当那死一般的静寂叠拢过来、将他包裹其中的时候，他终于明白过来，那流浪迷途般的感觉是什么了。他忽然觉得那样彻彻底底的孤独。

        “那么，我该干什么？”卡丁喊道。阿里曼转过身来，嘴唇微微张着，仿佛是为了辅助呼吸。他的肩背微微坍着。

        “等着，随你想怎样都行。”阿里曼迟迟地眨了眨眼，“我会召唤你的，卡丁。等时候到了的时候。”

        “成了么？”卡丁在阿里曼来得及转身前便问出了那问题，“你拿到我们需要的东西了么？”我们需要的… 哪怕是对卡丁，那言语也听上去显得陌生得几乎怪异。

        阿里曼转过头，望着他，讶异与痛楚交杂在他的面庞上。

        “嗯。”他说，“我们拿到了我们需要的。”

        “还有阿斯特罗斯 – 你知道他是否还活着么？”

        阿里曼依然彻彻地静着，没有动，他的目光凝然迎望着卡丁的。

        “没有别的选择了。”阿里曼说。一瞬之后，卡丁点了点头，依然感觉着那陌异的情感在他心中漫流。他点了点头，垂眼落开了目光。

        “我…”他抬起眼，开口，可阿里曼已经不见了，消失在视线之外，就仿佛他从不曾来到过。卡丁最后地瞥了一眼那敞开的舱室门，然后，跟向了阿里曼。那灼得焦黑的房间里没有什么需要守卫了，而今没有，也再不会有了。

        静寂在那两人都离开后落定降临。缓缓地，如此缓慢、以至于仿佛是静滞凝成的，玛罗斯自阴影间冒了出来。他停下在那灼得焦黑的舱室门口，不视的盲眼紧紧盯在卡丁离开的方向上。然后，他转头，直到他面朝着敞开的门、与其后的房间。

        + 你们明白了么？+

        阿里曼的思绪沉进了等待着的寂静里。

        萨纳赫特什么也没有说；他的身旁，密环的其他人继续注视着那巨大的水晶球，球内，柔而暗的色彩打着漩，仿佛在回声般呼和着一些人心中的疑虑。它的深处，阿波罗尼亚星系的影像缓缓旋转着，冰冷的光将那星系的四颗行星、还有膨臃的恒星勾勒。最外的那颗行星泛着荧荧的光，周围光晕似的环绕着普罗斯佩罗符文、还有延展至其外太空空间里的线条。那是颗气态巨行星，蓝与赭的星球表面翻腾着一道道庞大的风暴涡漩。萨纳赫特注视着云层的图案在他的目光下变化。以一则精神投影而言，它极其精准，几乎就仿佛它是从亲历的一手记忆里得来的一样。通常，阿里曼本会将心灵与他兄弟们的连起，以心灵相通的方式分享这般信息；可这一次，他将他们召来了西考拉克斯号的舰桥，以让他们得以用自己真正的眼亲见。萨纳赫特思忖着这是为什么。

        他向阿里曼所站立的、卡尔门塔指挥宝座前的地方瞥去。阿里曼穿着全副的战甲，面庞隐没在角盔之下。有力量在他周围的空气里电弧般跳荡，拂起他长袍的丝绸、还有铠甲上垂下的羊皮纸条，簌簌地轻响。那可是点新的东西，并且，还有些别的，某种原始未经雕饰、激情如热病一般的东西，含在阿里曼心灵说话的声音里。卡丁那驼背的身影站在一步之后的地方，手臂与双腿的活塞轻声地咝咝、哔剥，好似抽搐的肌肉。萨纳赫特注意到，那些仿生义体蒙上了一层湿漉漉的虹彩光泽，仿佛在渗着油污的汗水。他抬起目光，迎上两只碧色的狭窄竖瞳，对视着他。卡丁眨了眨眼，眼睑自眼角滑了过来。萨纳赫特强忍着厌恶的冷笑不要显露在脸上。

        + 目标是？+ 伊格尼斯问，他思绪的声音冰冷。

        + 神识之殿坐落在这卫月地表之下的迷宫中央。整个星系里，唯有这颗月有个名字 – 它被唤作阿波罗尼亚。+ 新明清亮的光一点点亮起在水晶球体之中，环起星系外侧行星附近一颗灰色的球。+ 那颗月、还有它的母星，它们的轨道排列被锁定在一个会带来永久的日食的位置上 *1。没有阳光照射到阿波罗尼亚。+

        + 一直藏在黑暗里。+ 萨纳赫特发送道。

        阿里曼转过头，望向萨纳赫特，却什么也没有说。那一眼目光令萨纳赫特的皮肤一阵汗毛倒竖，针刺似的微痛。

        + 防御如何？+ 伊格尼斯问。

        + 轨道防御，还有陆基炮组。+

        + 再没有别的了？+ 萨纳赫特传讯，+没有常驻守军？没有泰坦？没有我们那些小杂种狗表亲，终其一生地活在一间修道院里？+

        阿里曼摇了摇头。

        + 据那审判官知道的，再没有了，但我们应该做好它们可能存在的准备，以防万一。伊格尼斯，这任务是你的了。突破这颗卫星，将我送进迷宫里。+

        伊格尼斯点了点头，目光依然留驻在那球体上。

        + 还有哪些已知要素？+

        阿里曼顿了一下，不能更为轻微地耸了耸肩。

        + 有一社凡人将神识之殿守护 – 它的馆藏员。那便是那审判官如何称呼他们的。+

        +人类么？+ 伊格尼斯发送道，那思绪中，无感的平淡与难以置信激烈交锋着。

        + 是啊。最多十来人。+

        + 十来人？+

        + 那便是那审判官心灵里的。+ 阿里曼传讯。

        几人站成的圆环边缘，吉尔伽摩斯微微动了动，嘴唇不赞许地抿起在那张宽正的面庞上。随着疑虑自他兄弟敞开的心灵中涟漪般波荡开来，萨纳赫特尝到了那疑虑的味道。他向那曾经的黑鸦预言者望去，可吉尔伽摩斯正看着阿里曼。

        + 倘若这当真是我们寻找的地方，那么，帝国一定会要我们付出血的代价来将它攻破。+ 吉尔伽摩斯思绪的声音是隆隆然的，好似岩石碾磨在岩石上，+ 要塞之中，鲜少有门留敞而开。我展望过未来的路径，一一推演过命运的走向，可我看不见这一切要如何结局。不确然有如云雾一般将它笼罩。我不喜欢它。+

        + 你不喜欢它，是对的。+ 阿里曼说。很慢很慢地，他抬起手，解开了头盔的锁扣。其下的那张面容好似一张疲惫的面具。萨纳赫特感到一阵惊讶好似浪潮一般在密环里传荡开来。阿里曼环顾着他们每一个人，一道很淡的疲惫微笑凝在他的唇角上，却没有染上他的双眼，+ 我们走了那样远来到这里，已经付出了太多，并且，可能还要付出更多。没有什么确定无疑。也没有什么可以确定无疑。我们所筹划的不能、我们所打的这场战争，也不能。我们是在抗争命运，而不是被它引导、左右。总是有我们会失败、会陨落的可能的。+

        他顿住了，很短暂地闭拢了一瞬双眼，+ 可是，那正是它必然的模样。我们并不是行走在一条确然的道路上，我们是行走在一条打破命定之途的道路上啊。+

        静寂斥满了亚空间，颤抖着，好似一条绷紧的弦。然后，阿里曼自密环之中转过了身。水晶球里的影像消散不见。

        “伊格尼斯。”阿里曼说，他真实的声音从口中传出时细弱，“调动其余的舰队。我们会在一个周期内进行亚空间跃迁。你们其他人，召起你们的部队。”

        “我们要再次陪同您参与这次突击么，大人？”吉尔伽摩斯问。

        “不需要。萨纳赫特、卡丁、还有一小队红字会随我一起。”

        “遵您所愿。” 吉尔伽摩斯说。

        阿里曼背过身，离开了他们，甚至没有作出分别的示意。萨纳赫特想，他看见阿里曼的身影在边缘闪烁了一下，就仿佛被一束不存在的光短暂地投下了一瞬阴影。

        那么如此一来，我们就有机会了，萨纳赫特在自己心灵隐匿的边缘里暗自想着。他的周围，密环的其他人散开来去，不安而未定的思绪染在了亚空间里。赛拉博们自舰桥边缘无声无息滑了过来，在密环诸人离开留下的空间里柔声啼鸣。伊格尼斯是最后一个离开的。他迎上萨纳赫特的目光，不能更为轻微地，点了点头。
